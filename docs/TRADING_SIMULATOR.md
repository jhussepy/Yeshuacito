# Simulador de trading
Opera exclusivamente sobre datasets locales y capital ficticio. El tamaño es `riesgo monetario / distancia al stop`; R:R es recompensa potencial / riesgo; PnL respeta BUY o SELL; drawdown se mide contra máximo de equity. Antes de dimensionar, el motor exige `stop < entrada < objetivo` para BUY y `objetivo < entrada < stop` para SELL; una geometría contradictoria bloquea la ejecución y se explica al estudiante. Riesgo se limita a 5% en el motor y la UI recomienda 1%. Una pérdida bien gestionada recibe más XP que una victoria sin plan. No hay brokers, datos en vivo ni promesas de rentabilidad.
