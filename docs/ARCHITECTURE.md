# Arquitectura
Nexora usa una arquitectura modular por dominio. Las rutas de Next.js componen componentes pequeños; los motores puros de `features` no dependen de React ni Prisma y son fáciles de probar. `Course → World → Unit → Lesson → Exercise` permite sumar una futura academia de programación sin cambiar el reproductor. PostgreSQL es la fuente de verdad; el contenido demo de `data` también hace la experiencia navegable sin infraestructura.

Las escrituras entran por Route Handlers validados con Zod. La finalización de una lección se confirma en una única transacción: crea el intento y sus respuestas, actualiza dominio y progreso, y registra el movimiento de XP. La pantalla de resultado solo aparece después del commit. En producción, cada handler deberá recuperar la sesión HttpOnly, resolver el perfil y comprobar relaciones parentales. Los agregados del panel se derivan de intentos y transacciones, nunca de tracking externo.
